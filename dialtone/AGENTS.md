# Porting Dialtone to this crate

This crate is the Leptos port of Dialtone Vue components. view-sync is one consumer. New components go here, not under `view-sync/src`.

The Vue source is [dialpad/dialtone](https://github.com/dialpad/dialtone/). Components are `packages/dialtone-vue/components` on `staging`. Public exports are `packages/dialtone-vue/index.js`. Read props, slots, classes, and `data-qa` from that tree when porting.

Vendored assets are Dialtone 10.11.0 in `dialtone/assets` (`@dialpad/dialtone` 10.11.0, `@dialpad/dialtone-css` 9.4.0, `@dialpad/dialtone-icons` 5.5.0, `@dialpad/dialtone-tokens` 2.1.2). See `dialtone/assets/VERSION`. New ports follow tag `dialtone/v10.7.0`. Class names still have to be in `dialtone/assets/css/dialtone.css`, which is the Dialtone 10.11.0 bundle. Illustration and spot paint rules are the exception: they live in local `illustrations.css`, not in that bundle. A class that exists only on a later tag is recorded under the table. `d-slider*` is in that bundle. `d-slider--inverted` is not. `DtBanner` emits `d-banner--critical` and `d-banner--positive`. It does not emit `d-banner--error` or `d-banner--success`. The v10 names (`d-badge--positive`, `d-banner--critical` / `d-banner--positive`) are in the vendored CSS. `DtBadge` emits `d-badge--positive`. `success` is a deprecated alias of that class. Leave an existing port's class names until that component is the task. `DtAvatar` follows the Dialtone 10 avatar (rounded square, sizes `100`–`900`, OKLCH `data-avatar-family` / `data-avatar-variant`). Those rules are `.d-avatar` in the vendored CSS.

Static files live in `dialtone/assets`: `css/` (layered and `no-layers/`), `css/fonts/`, `fonts/`, and `css/no-layers/fonts/` (Season Mix and Season Sans), `icons/` (`@dialpad/dialtone-icons` 5.5.0, 626 SVGs, including `globe.svg`), `illustrations/`, `images/favicons/` and `images/spot/`, `tokens/` (including `layered/` and `no-layers/`), and `VERSION`. The other icon SVGs match the previous set, so named path data was not rewritten. `globe.svg` is not a named component. The no-layers stylesheets reference `fonts/` so a bundled stylesheet finds the woff2 files beside itself. The published package uses `../fonts/` from `css/no-layers/`. `illustrations.css` is local, in `css/` and `css/no-layers/`. The published CSS package does not ship `d-illustration` rules. This crate emits Dialtone class names. Apps import `css/no-layers/dialtone-default-theme.min.css` inside Tailwind `layer(base)`, then `tokens/layered/tokens-base-colors.css` and `tokens/layered/tokens-dp-colors.css`, then `css/no-layers/illustrations.css`, in that same layer. Dark mode is `data-dt-mode="dark"` on `html`. The app palette still uses `html.dt-theme-dark` and `html.dialtone-theme-dark`. `view-sync/tailwind.css` scans `../dialtone/src/**/*.rs` so a Tailwind utility used in markup is not purged.

`DtSkeleton` follows `dialtone/v10.7.0`. `animate` defaults to true and wins over an `animate` key inside an option. `animation_duration` is `animationDuration` (default `-1`). `-1` paints `animation-duration:1000ms`. `offset` defaults to `1`. The mixin multiplies that fallback position by `SKELETON_RIPPLE_DURATION` (`3000000`) and divides by `1000`, so the default delay is `3000ms`. `offset` `-1` omits the animation style. Vue reads `getBoundingClientRect` from a ref that is not reactive, and the docs page paints `3000ms`, so this port uses the `offset` prop and does not measure. `aria_label` is `ariaLabel`. `paragraph_option`, `list_item_option`, and `shape_option` take the option struct or `true`. `false` leaves that option unset. `text_option.style` is the inline `style`. `widths` is `width` when it is an array. `width` is the string form. `random_width` is `randomWidth`. A default list item sets it true. `min_width` and `max_width` are `minWidth` and `maxWidth` (30 and 100). A missing width uses `100%`, and the last row uses `38%`. Heading `sm`/`200` is `d-h-25`, `md`/`300` is `d-h-24px`, and `lg`/`400` is `d-h-50`. Shape `100` is 16px, `200`/`sm` is 24px, `300`/`md` is 32px, `400`/`lg` is 48px, and `500` is 64px. Any other size is a CSS length. Circle is `d-bar-circle`. Square is `d-bar-200`. Two option props warn with the Vue message. Vue uses `console.error`. Paragraph rows use `data-qa="skeleton-paragraph-row"`. Vue's template also emits an empty `contentclass` attribute from a bare identifier. This port omits it. Text, paragraph, and list roots still use `d-w100p`. `d-h-25`, `d-h-24px`, `d-h-50`, `d-bar-200`, and `d-skeleton*` are in the vendored CSS.

## How a port is shaped

Match the existing files. Leptos 0.8, `#[component]`, `use leptos::prelude::*;`.

- The doc comment names the Vue component: `Dialtone Vue \`DtCard\``.
- A prop whose Vue name differs is documented with that name in backticks (`maxHeight`, `contentClass`, `containerClass`).
- Rust prop names are snake_case. The component name stays `Dt` plus the Vue Pascal name.
- Optional strings use `#[prop(optional, into)]` and default to empty. Skip the extra class or the optional block when the string is empty, the way `DtCard` skips an empty `container_class`.
- Static defaults use `#[prop(optional, default = ...)]` with `&'static str` when the value is a token such as `"300"`, `"md"`, or `"top"`.
- A controlled value is `Signal<T>` plus `Callback<T>` (`DtInput` `value` / `on_input`, `DtToggle` `checked` / `on_change`). Read it with `.get()` inside a reactive class or `prop:`. Use `.get_untracked()` inside an event handler.
- An optional bool signal is `MaybeProp<bool>`.
- An optional element handle is `NodeRef<html::Input>` (or the matching `leptos::html` type).
- A named Vue slot that can be absent is `Option<ViewFn>`, rendered with `slot.run()` only when `Some`. That is the `v-if="hasSlotContent"` behavior. The default slot is `children: Children` when it is used once, or `ChildrenFn` when it is stored and called from more than one place.
- A slot that replaces another prop (`DtTooltip` `content` overriding `message`) is `Option<ViewFn>`.
- Markup uses the Dialtone classes (`d-card`, `d-card__header`, `d-icon--size-300`) and the Vue `data-qa` values. Do not invent a second class system.
- An extra class prop is appended: `format!("d-card {container_class}")`. A boolean modifier is `class=("d-toggle--checked", move || checked.get())`.
- Generated ids come from `unique_id("dt-toggle")` in this crate. If the caller passes a non-empty id, use that.
- Show and hide with `<Show when=...>` when Vue uses `v-if`.
- A tooltip or other Vue `appendTo: 'body'` overlay uses `leptos::portal::Portal`. Position it with `popper::compute_position`. Copy numeric Vue behavior into a named constant and comment the Vue source (`TOOLTIP_DELAY_MS`, offset `12`, z-index `400` / `651`).
- Icons are inline SVG components, not runtime fetches of `dialtone/assets/icons`. Those SVGs are still vendored there. A `DtIcon` with no child path draws an empty SVG. `DtIcon` is a 12×12 viewBox, `fill="none"`, `role="img"`, `data-qa="dt-icon"`. The `name` prop is the CSS suffix (`plus` → `d-icon--plus`), not an `ICON_NAMES` lookup. `size` defaults to `"500"`. `100`–`800` add `d-icon--size-*`. An unknown size warns and omits the size class. An empty `aria_label` sets `aria-hidden="true"`. A label sets `aria-hidden="false"`. An optional `class` is appended. Copy the `<path>` from the matching icon SVG. Add a `DtIcon{Name}` component in `icon.rs`. A new named icon takes `size` (default `"500"`), `class`, `aria_label`, and `data_qa`. The named icons in this crate already do. Close, ChevronDown, and ChevronRight document the extra class their callers pass.
- `web-sys` features belong on this crate's `Cargo.toml` when a component calls the DOM.

### Calls that fail the build

- `use leptos::context::Provider` (`DtCheckboxGroup`, `DtTextList`). `Provider` is not in the prelude. `use_context` is. Wrap the default slot in `<Provider value=context>`. A child with no provider still renders and warns.
- `#[prop(optional)]` on `Option<ViewFn>`, `Option<Callback<T>>`, `Option<String>`, or `Option<i32>` means the caller passes the inner value (`start=3`, `image_alt="Ada Lovelace".to_string()`, `DtAvatar` `group=12`). Passing `Some(...)` or an `Option<T>` does not type-check. `#[prop(optional, into)]` on `Option<Callback<T>>` accepts a closure. `#[prop(optional_no_strip)]` keeps the `Option`. `DtButton` `start_icon`, `end_icon`, `block_start_icon`, `block_end_icon`, `leading`, and `trailing` are that shape, and so are the matching slots on `DtSplitButton` and `DtFilterPill`. A `ViewFn` variable does not coerce. Write `start_icon=Some(icon)`. Omit the prop, or pass `None`, when the slot is empty.
- A `Signal<T>` prop without `#[prop(into)]` does not accept `RwSignal<T>`. `DtFilterPill` `filters` is that shape, so the caller writes `filters.into()`. `DtToggle` `checked` has `#[prop(into)]`, so an `RwSignal<bool>` passes directly. New controlled `Signal` props take `#[prop(into)]`.
- A `>` inside a `view!` attribute closes the tag. `on_change=move |next: Vec<DtFilter>|` fails to parse. In `view!`, write `move |next|`. A raw-string code sample can still show the typed closure and `.into()`.
- A `ViewFn` closure is `Fn`. Clone a captured `String` inside it. A `ChildrenFn` body does the same (`{body.clone()}`). Call `Children` once. A tag `match` moves that view into the taken arm and returns `.into_any()`.
- Vue props that are Rust keywords are `r#as` and `r#type` (`DtText`, `DtTextList`). The call site writes `as="p"` and `type="ordered"`.
- A boolean attribute Vue omits when false is `flag.then_some(true)` (`reversed` on `DtTextList`). Empty strings omit `aria-label`, `id`, and extra classes.
- Set a data attribute by its real name (`data-avatar-family=family` in `avatar.rs`). `attr:data-avatar-family` is emitted as a literal attribute name. A custom property the component sets (`--dt-text-line-clamp`) goes on `style`, not `attr:`.
- A prop that shares a name with a function in the same file shadows that function. `DtValidationMessages` calls `render_validation_messages` so the `validation_messages` prop does not hide the helper.
- Vue `v-html` is rendered as text. A prop Vue uses only as a list key (`DtValidationMessages` `id`) is accepted and not written to the DOM.
- Warn with `leptos::logging::warn!`. It prints in native tests and in the browser. Prefer that plus the Vue fallback over a panic. Document a case where Vue throws and this port warns (`DtText` headline-only size on a non-headline `kind`).
- Put a test-only fixture in the `#[cfg(test)]` module. Wasm `cargo check` does not compile tests, so a file-level `const` used only by tests warns as dead code.
- Copy the private `join_class` into the file. Use `list_nav::join_class` only when the file already uses `list_nav`. Keep `mod` private and `pub use` the public types when the file also has `pub(crate)` helpers (`validation.rs`). Other components are `pub mod` plus `pub use ...::*`.

## Leave app layout out of new primitives

A new component takes the Vue API, not an app's layout widths. `DtModal` follows `dialtone/v10.7.0` and does not include the mapping-editor widths.

Prefer a Dialtone class. The ports also use a few Tailwind utilities (`w-full`, `m-0`, `text-xs`, `text-fg-muted`, `max-w-none`). Those are scanned from this crate. A new utility class has to appear in the `.rs` source so that scan sees it.

## Read the Vue source

The repo is private. Fetch it with `curl`. This URL shape works: `https://raw.githubusercontent.com/dialpad/dialtone/dialtone/v10.7.0/packages/dialtone-vue/components/{Name}/index.js`. The contents API (`owner` `dialpad`, `repo` `dialtone`, ref `refs/tags/dialtone/v10.7.0`) works the same way. If the tag path 404s, the component was added later. Read it from `staging`, name that commit in the component doc and in the notes under the table, and grep `dialtone/assets/css/dialtone.css` before emitting the classes. `DtSlider` and `DtLoader` cite `dialtone/v10.11.0`. The emoji catalog still cites `dialtone/v9.190.0`. `d-text*` and `d-text-list*` are in the vendored CSS.

Read these, in order:

- The `.vue` template: element, class order, `data-qa`, aria, `v-if`, and slots.
- The script: props, defaults, validators, provide/inject, and emits.
- The constants file beside it. Class suffixes come from that map.
- The `*.test.js`. It names the default classes and which node carries `data-qa`. `DtButton` defaults to `base-button__button d-btn d-btn--primary`.

Copy `data-qa` from that test. When the test looks up one node for the `data-qa` and the role, id, or tabindex, render that node yourself. `DtTab` is a native `<button>` because `DtButton` hardcodes `data-qa="dt-button"` and captures `aria_selected` once. The button calls `button_classes` and appends `d-tablist__item`. Do not render it with `DtButton`: `disabled` would set the native attribute, and a new `DtButton` inside a class closure remounts and drops focus.

Vue `inject` from a parent that this task does not port becomes an explicit prop. Say so in the doc comment. Port a sibling the Vue index exports (`DtTextListItem`, `DtDropdownSeparator`, `DtDescriptionListItem`) in the same file when that sibling is part of the task. Leave an unrequested parent out. `DtTab` outside `DtTabGroup` warns and keeps its own `selected` flag, with the v10 default-kind classes. Inside the group, selection is the group's panel id.

Build the class string in the same order as the Vue computed array, and assert that full string in a unit test. A token missing from the constants map warns and is omitted. A token the template still emits (a marker on the wrong list type) stays in the class, with the Vue warning.

Grep `dialtone/assets/css/dialtone.css` for each new class. Record a missing name in the prose under the table. `html, body` set `font-size: 10px` there, so `1rem` is 10px. `--dt-spacing-200` and `--dt-layout-200` are defined in `dialtone/assets/css/dialtone-default-theme.css`. When one component's classes sit on a later Dialtone class, confirm the later rule is the one that should paint. `.d-tab` follows `.d-btn` and `.d-btn--primary`.

## Add a component

1. Read the Vue source as above. Read the closest file in the table and follow it.
2. Add `src/{snake_name}.rs`. One Vue component per file, plus an exported sibling from the same Vue folder.
3. In `src/lib.rs`, add `pub mod {snake_name};` and `pub use {snake_name}::*;` (or a private `mod` plus a narrow `pub use` when helpers stay `pub(crate)`). Add a row to the table above and delete the name from [Not ported yet](#not-ported-yet). A staging-only source or a class the vendored CSS lacks goes in the prose under the table.
4. From `nicholas.romero/pagerduty-sync`. The experimental repo root has no `Cargo.toml`.

```
cargo test -p dialtone --lib --target-dir /tmp/dt-port-host -- {module}::
cargo check -p dialtone --target wasm32-unknown-unknown --target-dir /tmp/dt-port-wasm
```

Use a fresh `--target-dir` while Trunk is serving `dialtone-demo`, so that wasm build stays put. The wasm check should add no warnings. Pure logic (placement math, class maps) gets a `#[cfg(test)]` module in the same file, as `popper.rs` does. Markup does not get a browser harness.

5. Stop at the crate unless the task includes `dialtone-demo`. That checklist is in `.grok/skills/port-dialtone/SKILL.md` under "Putting a port on the demo".

Consumers import the crate:

```rust
use dialtone::{DtCard, DtButton};
```

Do not reintroduce `mod dialtone` inside an app.
